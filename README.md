# Personal Blog Project - README

## Introduction
Welcome to the personal blog project created by our web development company. This project is designed to showcase advanced PHP 8 object-oriented programming skills and database management using PDO. This README file provides an overview of the project's functionality, along with installation and configuration instructions.

## Features
- **Article Management**  
  Add, edit, and delete articles with images, titles, subtitles, and descriptions.

- **Comments and Likes**  
  Registered users can comment on and like articles.

- **Authentication and Authorization**  
  Manage blog content, comments, and registered users.

## User Stories
### Administrator
- Add, edit, and delete articles.
- Manage comments and registered users.

### Registered User
- Comment on and like articles.
- View and update profile information.

### Visitor
- Browse published articles.
